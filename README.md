# Gemeinschaftspraxis Renst, Lübbel & Köhlmann

Eine moderne, responsive Beispielwebsite für eine fiktive Hausarztpraxis. Die Seite besteht ausschließlich aus HTML, CSS und einer kleinen Menge JavaScript – es ist kein Build-Schritt nötig.

## Lokal öffnen

1. Repository herunterladen oder klonen.
2. `index.html` per Doppelklick im Browser öffnen.

Alternativ im Projektordner einen kleinen lokalen Server starten:

```bash
python3 -m http.server 8000
```

Anschließend [http://localhost:8000](http://localhost:8000) aufrufen.

> Alle Namen, Kontaktdaten und Inhalte sind fiktiv. Die Online-Terminbuchung ist ein nicht funktionaler Demo-Link.
